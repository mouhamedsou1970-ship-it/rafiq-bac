# رفيق البكالوريا

تطبيق عربي لتنظيم دراسة طلبة البكالوريا في الجزائر. يجمع بين التخطيط الأسبوعي، القيود الزمنية، وضع التركيز، متابعة الدروس، ومساعد اختياري بالذكاء الاصطناعي.

## المميزات

- دعم شعب البكالوريا الجزائرية من إعدادات التطبيق.
- جدول دراسة مرن يراعي الارتباطات، أوقات الصلاة والحد اليومي.
- مخطط محلي ومخطط اختياري بالذكاء الاصطناعي.
- مؤقت تركيز وسجل للدراسة.
- مكتبة للدروس والمراجعة والاختبارات.
- تخصيص الواجهة والألوان.
- إشعارات المتصفح، مع تكامل اختياري مع Termux على Android.
- تصدير واستيراد نسخة احتياطية محلية.
- مفاتيح API يضيفها المستخدم بنفسه ولا تُضمّن في المستودع.

## التشغيل

يتطلب Node.js و npm.

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:8080`.

## البناء

```bash
npm run build
```

## الشعب

يمكن اختيار الشعبة من **الإعدادات ← الشعبة والمواد**. القوالب قابلة للتعديل من داخل التطبيق لأن المواد والمعاملات قد تتغير مع القرارات الرسمية بين المواسم. عند تغيير الشعبة تتغير المواد والمواد الأساسية المستخدمة في التخطيط تلقائيًا.

## الخصوصية

بيانات الدراسة تحفظ محليًا في المتصفح. عند استخدام مزود ذكاء اصطناعي، يُرسل الطلب إلى المزود الذي اختاره المستخدم وفق إعداداته وسياسة ذلك المزود.

## حالة المشروع

المشروع قيد التطوير، لذلك يُنصح بالاحتفاظ بنسخة احتياطية قبل التحديث بين الإصدارات الكبيرة.
